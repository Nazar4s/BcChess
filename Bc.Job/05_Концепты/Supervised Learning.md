**Supervised Learning (Обучение с учителем)** — ==это фундаментальный метод машинного обучения, при котором модель обучается на **готовом, размеченном наборе данных**==. У нейросети есть «учитель» — исторические данные, где для каждого примера (входа) уже известен правильный ответ (выход).
